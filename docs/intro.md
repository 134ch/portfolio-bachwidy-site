This site is a documentation-style portfolio. It holds case studies, articles, work evidence, services and contact details, and it documents how it was built.

The site is also a sample of its own subject. Every step of the build is written down, from the choice of framework to the checks that run on each change. You can read the process the way you would read a client's documentation.
